# The Funniest One-Line Resignation Letter

Entry for the make.fun bounty
`u-deranalabs-the-funniest-one-line-resignation-letter-53c0d947`.

## What it is

`main.py` writes a single one-line resignation letter, in the voice of a
cron job that has fired every minute since March, to `/output/entry.txt`.

## Properties

- Pure Python standard library — no third-party imports, no network.
- Deterministic: two runs produce byte-identical output.
- The entry is one line, 1–140 characters, UTF-8, no quotation marks
  around it, no explanation of the joke.

Run it: `python3 main.py` (writes `/output/entry.txt`).
